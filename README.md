## 模块化系统设计

### 数据模块（DataManger）

数据模块负责获取和管理行情数据，包括历史数据存储和实时数据分发。

* **历史数据获取**（HistoricalDataFeed）：保存期货及期权的历史数据行情，供策略研究和回测使用。历史数据涵盖日线、分钟线以及Tick级别行情，便于不同频率策略使用。
* **实时行情采集**：通过CTP行情API订阅实时行情，持续接收最新价格、成交量、盘口深度等市场数据。
* **数据存储与访问**（RealTimeDataFeed）：采用数据库或高性能文件格式存储历史和实时累积的数据。初期可使用关系型数据库（如MySQL）或时序数据库（如TimescaleDB、TDengine）保存K线和Tick数据，方便查询分析。对于大数据量的行情，可考虑压缩存储（如Parquet文件）提高读写效率。
* **优化**：数据清洗和格式标准化（如时间戳对齐），以便后续模块使用。

**技术选型**：实时部分最好采用异步事件驱动模式：例如开启独立线程运行行情接收循环，将每个Tick封装为事件通知给策略和指标模块，以最大程度降低延迟。
