01 / PROJECT

每个环节，各有分工。

数据、研究与应用，在同一个工作区协作。

gr-data · gr-db

数据基础

供应商数据采集、归一化与入库。PostgreSQL 统一保存行情，DDL 与迁移集中管理。

gr-backtest

策略回测

独立的回测引擎，承接历史数据、策略执行与结果分析，支持生成 HTML 报告。

gr-signal

实盘信号

负责实盘信号生产与交易执行。策略上线遵循历史回测、模拟盘、小资金实盘的验证顺序。

gr-factor

因子研究

期权定价与因子分析能力，支持量化研究中的模型计算与分析。

gr-api · apps/web

应用与诊断

FastAPI 与 React 连接策略、选股和持仓诊断。诊断部分计算仍在建设，支持范围以接口指南为准。

gr-tools

公共工具

复用环境加载、日志、文件系统与表格读取能力，为各业务模块提供基础支持。
